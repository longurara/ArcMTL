# ArcMTLDriver process allow-list (/Library/GPUBundles/arcmtl-allow.txt)
# Rules are evaluated top-to-bottom:
#   -ProcessName   Deny Metal device creation in ProcessName
#   !ProcessName   Allow only when ArcAccel framebuffer mode is armed (debug.arcaccelfb=1)
#   ProcessName    Allow ProcessName
#   *              Allow all remaining user applications & CLI compute workloads

# WindowServer and core macOS desktop shell processes are gated with '!':
#  1. In Dual-GPU headless mode (boot-arg arc_headless=1 -> debug.arcaccelfb=0),
#     desktop shell & Terminal stay on RTX 4070 so the GUI can never turn black,
#     while mtl_offscreen_test, benchmarks, apps, and ARCMTL_ENABLE=1 see BOTH GPUs!
#  2. In Standalone Arc Desktop mode (arcfb=1 arcaccel=1 -> debug.arcaccelfb=1),
#     '!' evaluates to ALLOW so the entire macOS desktop composites on Intel Arc.
!WindowServer
!loginwindow
!Dock
!Finder
!SystemUIServer
!ControlCenter
!NotificationCenter
!WallpaperAgent
!WallpaperVideoExtension
!Spotlight
!Terminal

# Grant Metal 3 access on Intel Arc (Xe-LPG) to all applications & compute tools
*
